# Saint's SMS Service - Telegram Bot Store

Telegram бот-магазин с интеграцией CryptoBot для приема криптоплатежей.

## Особенности

- 🛒 Магазин товаров с категориями и подкатегориями
- 💳 Оплата через CryptoBot (USDT, BTC, ETH и другие криптовалюты)
- 👤 Профиль пользователя с историей покупок
- 📋 FAQ с правилами и поддержкой
- 🎨 Современный интерфейс с inline клавиатурами
- 👥 Реферальная система (10% бонус от пополнений)
- 📊 Веб-админ панель для мониторинга статистики

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd "Saint's SMS Service"
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте конфигурацию в `settings.ini`:
```ini
[settings]
token=YOUR_BOT_TOKEN
admin_id=YOUR_ADMIN_ID
comment_pay=SAINTS
cryptobot_token=YOUR_CRYPTOBOT_TOKEN
```

4. Запустите бота:
```bash
python main.py
```

## Настройка

### Получение токенов

1. **Bot Token**: Получите у [@BotFather](https://t.me/BotFather)
2. **CryptoBot Token**: Получите у [@CryptoBot](https://t.me/CryptoBot)

### Настройка базы данных

База данных SQLite создается автоматически при первом запуске. Все таблицы и начальные данные настраиваются автоматически.

Бот использует изображения для создания красивого интерфейса:

- **купить.jpg** - отображается при переходе в магазин
- **профиль.jpg** - отображается при просмотре профиля

## Реферальная система

Бот включает полноценную реферальную систему:
- **Генерация ссылок**: Каждый пользователь получает уникальную ссылку в профиле.
- **Бонусы**: 10% от каждого пополнения реферала мгновенно зачисляются на баланс пригласившего.
- **Уведомления**: Реферер получает сообщение при каждом начислении бонуса.
- **Статистика**: Просмотр количества приглашенных и общего заработка в боте и админ-панели.

### Активация и настройка

Реферальная система активируется автоматически при запуске бота. Если вы обновляете существующего бота, выполните SQL-миграцию для добавления необходимых таблиц.

### SQL Миграция (для существующих БД)

```sql
-- Добавление колонки пригласившего в таблицу пользователей
ALTER TABLE UserList ADD COLUMN inviting INTEGER DEFAULT 0;

-- Создание таблицы истории реферальных начислений
CREATE TABLE IF NOT EXISTS ReferralHistory (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    referrer_id INTEGER,
    referral_id INTEGER,
    amount_topup REAL,
    amount_bonus REAL,
    date TEXT,
    FOREIGN KEY (referrer_id) REFERENCES UserList (user_id),
    FOREIGN KEY (referral_id) REFERENCES UserList (user_id)
);
```

# 📱 SMS Rent Bot

Telegram-бот для аренды виртуальных номеров с публичным REST API. Работает через 5sim как провайдер, с собственной наценкой и поддержкой нескольких платёжных систем.

## ✨ Возможности

### Для пользователей
- Аренда виртуальных номеров для любых сервисов (Telegram, WhatsApp, VK и др.)
- Выбор страны, оператора и сервиса
- Автоматическое получение SMS-кода — бот присылает уведомление и закрепляет сообщение с кодом
- Пополнение баланса через **CryptoBot** и **XRocket**
- История заказов и баланс

### Для администраторов
- Отдельная веб-админ-панель (FastAPI + отдельный сервер)
- Управление пользователями, балансами, логами действий
- Рассылки по пользователям
- Статистика продаж
- Кастомная цена для конкретного пользователя по любому сервису/стране

### Публичный REST API
Любой пользователь бота получает API-ключ и может работать через HTTP:
- `GET /api/v1/services` — список всех сервисов
- `GET /api/v1/countries?service=tg` — страны и цены для сервиса
- `GET /api/v1/prices?country=russia&service=tg` — цены по операторам
- `POST /api/v1/buy` — купить номер (поддерживает `operator=any` для выбора самого дешёвого)
- `GET /api/v1/check/{order_id}` — статус и SMS-код
- `POST /api/v1/cancel/{order_id}` — отмена с автовозвратом
- `GET /api/v1/orders` — история заказов с фильтром по статусу

## 💰 Система ценообразования

Динамическая наценка поверх себестоимости 5sim:

| Базовая цена | Наценка |
|---|---|
| < $3 | +100% |
| $3 — $5 | +30% |
| > $5 | +15% |

Финальная цена дополнительно включает комиссию CryptoBot (3%). Для отдельных пользователей администратор может выставить фиксированную цену по любому сервису.

## ⚙️ Фоновый чекер

Каждые 5 секунд фоновая задача опрашивает активные заказы:
- Получено SMS → уведомление пользователю + закрепление сообщения + автозавершение в 5sim
- Истёк таймаут (15 мин) → автоотмена + возврат средств
- Отменён со стороны провайдера → возврат средств

## 🛠 Стек

- **Python 3.11**
- **aiogram 2.25** — Telegram Bot
- **FastAPI + Uvicorn** — REST API и админ-сервер
- **SQLAlchemy 2.0 async + aiosqlite** — база данных (SQLite)
- **5sim API** — провайдер номеров (через абстрактный `BaseSMSProvider`, провайдер легко заменяется)
- **CryptoBot / XRocket** — приём крипто-платежей
- **Docker / systemd** — деплой

**1. Клонируй репозиторий и установи зависимости:**

**4. Запусти админ-сервер (отдельно):**

```

Любой пользователь бота получает API-ключ и может работать через HTTP:
- `GET /api/v1/services` — список всех сервисов
- `GET /api/v1/countries?service=tg` — страны и цены для сервиса
- `GET /api/v1/prices?country=russia&service=tg` — цены по операторам
- `POST /api/v1/buy` — купить номер (поддерживает `operator=any` для выбора самого дешёвого)
- `GET /api/v1/check/{order_id}` — статус и SMS-код
- `POST /api/v1/cancel/{order_id}` — отмена с автовозвратом
- `GET /api/v1/orders` — история заказов с фильтром по статусу

## 💰 Система ценообразования

Динамическая наценка поверх себестоимости 5sim:

| Базовая цена | Наценка |
|---|---|
| < $3 | +100% |
| $3 — $5 | +30% |
| > $5 | +15% |

Финальная цена дополнительно включает комиссию CryptoBot (3%). Для отдельных пользователей администратор может выставить фиксированную цену по любому сервису.

## ⚙️ Фоновый чекер

Каждые 5 секунд фоновая задача опрашивает активные заказы:
- Получено SMS → уведомление пользователю + закрепление сообщения + автозавершение в 5sim
- Истёк таймаут (15 мин) → автоотмена + возврат средств
- Отменён со стороны провайдера → возврат средств

## 🚀 Запуск

**1. Клонируй репозиторий и установи зависимости:**
```bash
git clone https://github.com/dolezhaty/sms-rent-bot.git
cd sms-rent-bot
pip install -r requirements.txt
```

**2. Создай `.env` файл:**
```env
BOT_TOKEN=your_telegram_bot_token
FIVESIM_API_KEY=your_5sim_api_key
CRYPTOBOT_TOKEN=your_cryptobot_token
XROCKET_TOKEN=your_xrocket_token
ADMIN_IDS=123456789
```

**3. Запусти бота:**
```bash
python main.py
```

**4. Запусти админ-сервер (отдельно):**
```bash
python run_admin.py
```
